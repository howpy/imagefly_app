1. Introduction

View/Search Dragonfly Publications is a lite-Obsidian viewer for browsing and full-text searching a collection of publications that USED Dragonfly. The papers ship as markdown bundled inside the plugin and work fully offline.

This feature is provided by a third party (Prototype Labs / Apps), not officially developed or supported by Dragonfly. The content is auto-summarized; the original text and copyright belong to the respective publishers — refer to each paper's DOI for the source.

2. The interface

1. Left — a search box + a relevance filter (All / High / Medium) + a tree of papers grouped by discipline (each with a relevance badge 🟢 High / 🟡 Medium; disciplines such as Materials Science & Engineering, Life Sciences & Biology, Medical & Preclinical, Palaeontology & Geoscience, …).

2. Right — the selected paper rendered, with three buttons at the top to switch between English / 中文 / Full text.

3. Search — full-text substring matching over title/authors/body; works in any language (Chinese searches directly, e.g. 分割, 孔隙).

3. Where the papers come from & how to update

The papers come from the All_Materials_Organized_by_AI project, which turns each paper into an English summary / Chinese summary / full-text markdown trio and has an LLM rate its Dragonfly Relevance (High/Medium/Low/None). This plugin bundles the ~91 papers filtered to High + Medium.

To update: run export_dragonfly_publications.py in the All_Materials_Organized_by_AI project to re-export, then repackage this project — the plugin code needs no change. Only the markdown (~6 MB) is bundled, never the original PDFs/videos.

4. Requirements

No install, no internet, no GPU, no venv. A pure viewer: it reads the bundled markdown under pub_viewer_code\pubs and renders it with Qt's native markdown renderer; it does not use the Dragonfly object model.
