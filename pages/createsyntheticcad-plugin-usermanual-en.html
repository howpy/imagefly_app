Version 1.0 · 2026-07-26


1. Introduction

Create Synthetic CAD Models (STEP) builds real CAD solids from a menu of preset parametric shapes/designs and writes them as STEP files. On Dragonfly 2027.1+, it can also load a STEP into the current scene as a Mesh with one click.

Geometry is built with the open-source cadquery library (OpenCASCADE / cadquery-ocp, Apache-2.0), running in the plugin's dedicated venv as a subprocess so it never touches Dragonfly's own Python. All dimensions are in millimetres (mm).

On Dragonfly 2027.1 (Python 3.14) the bundled Python cannot build this environment: install a python.org Python (3.12, 3.13 or 3.14) and enter it in the panel's Base Python field; Dragonfly 2025.1 needs no separate Python.

This feature is provided by a third party (Prototype Labs / Apps), not officially developed or supported by Dragonfly. Use at your own risk.

2. Available shapes

Shapes are organised into three groups in the dropdown:

  • Primitives: box, cylinder, sphere, cone/frustum, torus, square pyramid, wedge.
  • Mechanical Parts: hex bolt, hex nut, washer, spur gear, L-bracket, bolt-circle flange, pipe.
  • Test Artifacts: hole-array plate (CAD porosity phantom), step gauge, sphere-on-stem (CT), perforated cube, fillet/chamfer block.

Selecting a shape lists its parameters (length/width/height, radius, tooth count, hole diameter, …) for you to edit.

3. How to use

1. Pick a shape/design from the dropdown and set its parameters.

2. Confirm the STEP output folder under 'Output' (or 'Browse…').

3. First time only: click '⚙ Setup Environment' once to build the cadquery venv (needs internet, a few hundred MB).

4. Click 'Create CAD Model and Save STEP File' — a <shape>_<timestamp>.step appears in the chosen folder.

5. (Optional) Click 'Load to Dragonfly' to import the STEP you just created as a Mesh.

4. Requirements

The first 'Setup Environment' builds a venv at %LOCALAPPDATA%\DragonflyPrototypeLabs\CreateSyntheticCAD\venv (a short path, to keep OpenCASCADE DLLs under the Windows MAX_PATH limit) from Dragonfly's own Python and installs cadquery + numpy. After that, generation needs no internet and no GPU.

'Load to Dragonfly' works only on Dragonfly 2027.1+ (older versions have no STEP import). On older versions the button is disabled with a tooltip; the STEP file is still produced for use in other software.

5. Tips

  • STEP is a B-rep (exact boundary) solid; loading into Dragonfly triangulates it into a Mesh via OpenCASCADE (MeshHelper.importSTEPFile).
  • The STEP files are also ready for downstream meshing, FE/CFD simulation, reverse engineering, or as standard parts for algorithm testing.
