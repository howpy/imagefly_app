Version 1.0 · 2026-07-26


1. Introduction

Auto Backup & Exit gives you a single 'back up and quit Dragonfly' button: capture the current session's scene in one click, then quit Dragonfly — and optionally shut the computer down afterwards.

This feature is provided by a third party (Prototype Labs / Apps), not officially developed or supported by Dragonfly. The fast steps run entirely in-process with no internet. Shutdown is off by default and requires an explicit tick plus confirmation.

2. What one backup contains

Ticked optionWhat is written
Session snapshotmain-window screenshot, per-view screenshots, a list of published objects (objects.txt), and a saved session file session.ORSSession
Object-connections graph (PNG)the relationship graph drawn by the Show Connections plugin, saved as object_connections.png
Current view screenshot (PNG)a screenshot of the currently active view, current_view.png
AI Work Logreuses the WorkLog plugin and its local LLM to turn the day's logs into Markdown (runs only if WorkLog is set up)

Each run creates a timestamped subfolder under the backup folder you pick (e.g. backup_20260726_180000); all of the above are written into that subfolder.

3. Two buttons / exit and shutdown

  • Backup now (keep open): runs only the ticked backup steps, then opens the folder for review; Dragonfly stays open.
  • Backup & Exit Dragonfly: backs up, asks for confirmation, then quits Dragonfly cleanly. Because the session was just saved, quitting does not re-prompt to save.
  • Shut down after exit (optional): when ticked, a Windows shutdown is scheduled before quitting (shutdown /s /t 60). Within the 60-second countdown you can cancel it by running shutdown /a.

4. How it works (technical path)

  • Reuse, not re-implement: the object-connections graph calls the Show Connections plugin and the AI Work Log calls the WorkLog plugin directly; this plugin locates those two sibling plugins automatically inside the packaged directory (GenericMenuItems).
  • Threading: fast steps (screenshots / save session / object graph) run on the UI thread; the slower AI Work Log (local LLM) runs on a background thread so the UI never freezes.
  • How it exits: a clean event-loop quit (QApplication.quit), rather than the close flow that triggers the save guard — because the session was already saved during the backup.

5. How to use

1. Menu Prototype Apps ▸ Auto Backup & Exit… to open the panel.

2. Choose a backup folder (default: your home\DragonflyBackups).

3. Tick what to include (session snapshot / object-connections graph / current-view screenshot / AI Work Log; and whether to shut down after exit).

4. Click 'Backup now' to back up without exiting; or click 'Backup & Exit Dragonfly' and confirm to back up and quit (then shut down, if ticked).

6. Requirements

The fast steps need no install/internet/GPU/venv. The object-connections graph requires the Show Connections plugin to be installed alongside; the AI Work Log requires the WorkLog plugin plus its one-time setup (local model + venv), and is skipped when not set up. Shutdown is Windows-only.
