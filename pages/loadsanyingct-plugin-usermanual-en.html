1. Introduction

Load Sanying CT Image Files imports Sanying (三英) micro-CT reconstructed RAW volumes into Dragonfly. After reconstruction the Recon folder typically holds FdkRecon-<type>-<X>x<Y>x<Z>.raw (default ushort = 16-bit unsigned) and a Reconstruct.txt. The plugin auto-parses these, previews a mid-slice, and loads the volume as an image Channel.

This feature is provided by a third party (Prototype Labs / Apps), not officially developed or supported by Dragonfly. Use at your own risk.

2. How dimensions & parameters are determined

Parameters come from the [ReconstructItem] section of Reconstruct.txt plus the raw filename:

  • X = VoxelX, Y = VoxelY (always from the txt).
  • Z: for a circle-trajectory scan (CircleNum = 1) use VoxelZ; for a helical scan (CircleNum ≠ 1, e.g. 4) VoxelZ is wrong, so Z is the 3rd integer in the raw filename.
  • Voxel size = VoxelDis (millimetres, isotropic).
  • Data type defaults to 16-bit unsigned (the ushort in the filename).

The plugin also cross-checks against the file size and auto-corrects Z if needed. Every parameter is editable in the panel.

3. How to use

1. Click 'Browse File…' to pick FdkRecon-*.raw, or 'Browse Folder…' to pick the Recon folder (the raw is found automatically).

2. Check the auto-detected dimensions / data type / byte order / voxel size / scan mode (edit if needed).

3. For very large volumes, pick a Downsample factor or set Z from / Z to to load a sub-range; the estimated loaded size is shown.

4. Use 'Preview mid-slice' to confirm the read is correct.

5. Click 'Load into Dragonfly' — the volume appears as a new image Channel in the object list.

4. Requirements

No install, no internet, no GPU, no venv. Reads with Dragonfly's own numpy via memory-mapping, slice-by-slice for big volumes; downsampling is stride subsampling, so peak memory ≈ one slice + the output volume.
