1. Introduction

Half-Height Slope Width measures the width between the two half-height slope crossings of the intensity profile along a ruler: the profile is sampled on a selected channel along a selected ruler (100 points), the internal peak or valley is found automatically, the half-height point (midpoint between baseline and extremum, linearly interpolated) is located on each slope, and the width between the two points is reported in millimetres — optionally publishing a new ruler spanning them. This is the Prototype Apps port of the legacy local plugin CalWidthOfHalfHighSlope (计算半高坡宽度).

This feature is provided by a third party (Prototype Labs / Apps), not officially developed or supported by Dragonfly. Unlike the legacy plugin, it imports nothing heavy at Dragonfly startup.

2. Two ways to use it

  • Panel: menu Prototype Apps > Half-Height Slope Width..., pick a channel and a ruler, click Calculate; tick the publish option to also create a new ruler at the half-height points (titled '<ruler> (half-height)').
  • Right-click (legacy flow): select a ruler in the object list > right-click > 'Half-Height Slope Width 半高坡宽度': one click computes and shows the result, with an 'OK + new ruler' option. With multiple channels a picker appears first.

The right-click entry carries a marker - and this manual quotes its name without one. On Dragonfly's own right-click menu the entry is displayed with one glyph in front of its name, ● by default, so you can see at a glance that Prototype Apps added it and Dragonfly did not; Dragonfly's own entries never carry one. So the entry's name is Half-Height Slope Width 半高坡宽度, and with the default marker it reads ● Half-Height Slope Width 半高坡宽度 on the menu.

The marker is not a setting of this plugin. It is one setting shared by all of Prototype Apps, and it lives in a DIFFERENT plugin's panel: Custom Context Menus ▸ the 1 Entries tab ▸ the Mark our entries on Dragonfly's menus group. There you can pick another glyph (•, ▪, @) or choose no marker to switch the feature off completely, and every marked entry across the plugins changes with it. Dragonfly rebuilds this entry on every right-click, so a change shows at your next right-click - no restart. The setting lives in a shared file outside both plugins, so your choice - including no marker - still applies to this entry when Custom Context Menus is not installed or is disabled in the App Store. What you lose in that case is only the place to CHANGE it: there is then no panel offering the choice, and an installation that never made one shows the default marker.

3. Algorithm

1. Sample 100 equidistant mean-intensity points along the ruler (the same API as Dragonfly's profile tool).

2. Find the internal extremum: compare the internal max/min deviation from the mean of the two end baselines; take the larger (peak or valley).

3. Left slope: target amplitude = (left baseline + extremum)/2, crossing found by linear interpolation; right slope likewise.

4. Width = distance between the two half-height points, converted to millimetres from their world coordinates.

An extremum at a ruler end, a monotonic profile, or fewer than 3 samples produce clear error messages instead of failures. Unit-tested against a triangle profile and a Gaussian (matches the analytic FWHM).

4. Requirements

No install/internet/GPU/venv. Needs at least one Channel and one ruler annotation in the session.
